# `rayohx`

Command line interface for <span style="font-weight: bold">RayoHX</span>.

**Usage**:

```console
$ rayohx [OPTIONS] COMMAND [ARGS]...
```

**Options**:

* `-V, --version`: Show the version and exit.
* `-v, --verbose`: Show extra detail.  [env var: RAYOHX_VERBOSE]
* `-q, --quiet`: Only show errors.  [env var: RAYOHX_QUIET]
* `--no-color`: Disable colored output.  [env var: RAYOHX_NO_COLOR]
* `--install-completion`: Install completion for the current shell.
* `--show-completion`: Show completion for the current shell, to copy it or customize the installation.
* `--help`: Show this message and exit.
