# Support

- **Start with the docs:** the [README](README.md) covers installing and using the library, and the [Python guide](docs/guides/python.md) goes into detail. The [docs](docs/README.md) cover how it is built.
- **Questions and ideas:** use [GitHub Discussions](../../discussions) if enabled, otherwise open an issue.
- **Bugs:** open an issue with the bug report form. Say which part is affected, your operating system and version, your Python version, and how you installed it. For the command line, Docker image, desktop window or installers, open the issue in their own repository (listed in the [README](README.md#other-ways-to-use-rayohx)).
- **Security problems:** see [SECURITY.md](SECURITY.md).
