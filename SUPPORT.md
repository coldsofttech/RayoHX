# Support

- **Start with the docs:** the [README](README.md) covers installing and using the tool, and each package has its own README and guides: [library](packages/core/README.md), [command line](packages/cli/README.md), [API](packages/api/README.md), [Windows window](packages/ui/README.md) and [Docker image](packages/docker/README.md). The [docs](docs/README.md) cover how they fit together.
- **Questions and ideas:** use [GitHub Discussions](../../discussions) if enabled, otherwise open an issue.
- **Bugs:** open an issue with the bug report form. Say which part is affected (library, command line, API, window or Docker image), your operating system and version, and how you installed it. For the window, also say whether the Microsoft Edge WebView2 runtime is installed.
- **Security problems:** see [SECURITY.md](SECURITY.md).
